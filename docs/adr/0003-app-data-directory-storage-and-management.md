# 0003: 应用数据存储目录呈现与跨平台一键打开设计

## Context
SylixScope 在本地持久化存储 SQLite 录制数据库（`history.db`）与配置状态。用户与开发者需要清楚了解应用在不同操作系统（macOS、Windows、Linux）上的数据存储绝对路径，并能在排查问题、备份数据或管理磁盘空间时快速在系统文件管理器中打开该目录。

## Decision
1. **数据目录规范与自动创建**：
   后端统一通过 `app.path().app_data_dir()` 获取各操作系统标准的应用数据目录。在获取与打开时，执行幂等创建确保目录存在。
2. **跨平台文件管理器唤起**：
   在 Tauri 后端结合 `tauri-plugin-opener` 与各桌面操作系统原生文件管理器调用命令（macOS: `open`, Windows: `explorer`, Linux: `xdg-open`），保证在各种 Linux 桌面环境、Windows 及 macOS 上的高可用打开体验。
3. **全局配置 2x2 对称卡片布局**：
   在前端 `SettingsView` 增加“数据存储与持久化”卡片，展示等宽路径、一键复制功能和打开目录主操作，与资源预警、外观主题、字号配置构成一致的 2x2 响应式网格。

## Rationale
- **降低心智负担**：用户无需手动寻找深层隐蔽的 AppData / Application Support 目录，可视化展示增强系统透明度。
- **全平台鲁棒性**：双层打开机制与自动创建保证了在全新安装或自定义桌面环境下均不会报错。
