# 0006: 内存分段按真实比例渲染（移除视觉钳制）

## Context
`MemDistributionCard` 为避免数值抖动引发布局跳动，将内存使用率的可视宽度钳制在 30%–70% 区间，并给内核/应用/缓冲各段设置了 24%/34% 的最小占比。结果是看板图形与真实内存分布系统性偏离：小占比分段被放大、大占比被压缩。这与"数据至上"的第一设计原则冲突——监控工具的图形本身就是数据陈述，失真即误导。经真实比例 / 钳制加明示 / 单条堆叠条三种形式的原型对比，用户确认选择真实比例。

## Decision
内存状态与分配卡按**真实比例**渲染：移除使用率钳制与最小占比逻辑，所有分段（内核/堆、应用占用、其它缓冲、空闲物理）按真实字节比例映射到固定高度的容器中。占比过小的分段不在段内嵌文字，依赖底部图例与精确数值保证可读性；容器高度固定，数值波动只改变分段边界，不引发布局重排。

## Rationale
1. **可视化诚信**：性能分析与问题定位依赖对内存分布的直观判断，图形与数值不一致的危害大于任何美观损失。
2. **抖动已有更合适的解法**：布局稳定性由固定容器与边界动画承担，不需要以失真为代价。

## Consequences
- 空闲或缓冲占比极小（如 < 8%）时，对应分段在图内仅呈现为色块，读数以图例为准。
- 录制回放与 MCP 工具消费者引用的内存分布比例与图形渲染保持一致，无需区分"视觉值"与"真实值"两套口径。
