# 0005: 视觉世界收敛为纯平工业指挥台（去玻璃拟态与装饰动效）

## Context
PRODUCT.md 的反参考明确禁止 SaaS 商业化渐变、低对比浅灰字与装饰性动画，但 DESIGN.md 与实际实现（`.glass-card` 毛玻璃、极光光晕背景、悬浮位移、8 组装饰关键帧）长期停留在一套"玻璃拟态 + 光晕"的视觉世界上，两份设计评审（MonitorView 25.5/40、App 23/40）均点名毛玻璃滥用与无语义动效问题。用户进一步明确设计意图：现有界面"过于卡通、不够严肃"，此前已通过全局圆角统一为 2px 迈出第一步。经过纯平指挥台 / 收敛玻璃 / 暗色氛围舱三个方向的可交互原型对比，确认了收敛方向。

## Decision
采用**纯平工业指挥台**作为唯一视觉世界：
1. 卡片为实色背景 + 1px 边框，全局 2px 圆角；移除 backdrop-blur 毛玻璃、极光光晕、hover 悬浮位移与所有无语义动画。
2. 仅保留具备功能语义的动效：告警呼吸提示、录制中闪烁、连接进行中的进行时指示。
3. 明暗双主题并列保留，重点修复浅色模式小字对比度；装饰色彩全部收敛到语义变量（正常/警告/危险），数据主色与告警色分离。
4. 形状语言方正化：状态点、徽章、进度条不再使用胶囊/圆形（圆形仅保留给仪表盘刻度等真正需要圆形的部件）。

## Rationale
1. **数据至上**：纯平实色与高对比边框让波形和数值成为唯一视觉重心，符合工程环境长时间注视的阅读需求。
2. **性能**：大面积 backdrop-filter 与多层阴影的 GPU 合成开销被评审列为 P1 问题，纯平渲染成本显著更低。
3. **严肃感即产品定位**：面向嵌入式工程师的监控驾驶舱，克制、方正、高信息密度比圆润、发光更符合用户对"专业工具"的预期。

## Consequences
- DESIGN.md 需整体重写：旧"纯净石墨工业驾驶舱"条目中的玻璃卡片、光晕描述作废，以本决策与最终色板为准。
- 既有 `rounded-full` 胶囊样式（状态点、徽章、侧栏按钮等约 45 处）需在本轮治理中一并方正化。
- `--glass-card-*`、`--aurora-glow-*` 等 token 失效删除，组件样式统一走语义 token。
