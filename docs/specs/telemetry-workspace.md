面向在实验室或现场通过 Telnet 诊断 SylixOS 板卡的工程师。沿用既有采样、告警阈值、进程、网络、录制和回放数据。

## Direction contract

**THESIS** — 先用共用时间轴找出越阈时刻，再就近检查活跃进程。当前读数、采样曲线和排查入口位于同一首屏。

**OWN-WORLD** — 冷石墨工作面、深青导航、青白 CPU 线、淡紫虚线内存和琥珀越阈刻线。正文沿用自带的中文字体，等宽数字只用于数据。

**STORY** — 连接板卡，比较两种资源的趋势，暂停并锁定采样时间，再检查进程。网络、历史、设置延续同一套导航与工作区层级。

**FIRST VIEWPORT** — 左侧导航，页头常驻连接状态和操作。同一资源面板左列显示读数，右侧图表用轴上刻线标记越阈采样。进程列表紧接资源面板。

**FORM** — 共用时间轨，第二轮目录挑战者 `operate-c-emission-line-rail`。seed:8e048f050c37d7a3。
